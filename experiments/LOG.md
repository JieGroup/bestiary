# Experiment log

One line per run. Newest at the bottom. Keep it terse — the config file holds the
detail, this file is the index.

Format: `date | config | steps | hypothesis | outcome`

Checkpoints and ONNX exports are gitignored. Note the checkpoint directory name so
the run can be found again on the pod.
